## Setup

### 1. Install dependencies
```bash
pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn streamlit
```

### 2. Place the dataset
Download `insider_threat_clean_dataset.csv` from Kaggle and place it in the project root.

---

## Running the Notebooks

Run in order inside Jupyter:

```
01_data_exploration.ipynb   → Understand the data
02_preprocessing.ipynb      → Clean, encode, SMOTE, save artifacts
03_model_development.ipynb  → Train RF, DT, LR; evaluate; save best model
04_explainability.ipynb     → Feature importance, risk narratives, TP/FP/FN analysis
```

> **Important:** Run notebook 02 before 03, and 03 before 04. Each notebook saves
> artifacts that the next one loads from the `models/` directory.

---

## Running the Prototype

```bash
streamlit run app.py
```

The app opens at `http://localhost:8501` and offers two modes:

| Mode | Description |
|---|---|
| **Manual Entry** | Enter a single employee's behavioural profile via form fields |
| **Upload CSV** | Batch-analyse many records at once |

### Output for each record
- Classification: **NORMAL** or **MALICIOUS**
- Confidence score (probability of malicious intent)
- Risk level: Low / Medium / High / Critical
- Feature importance chart
- Plain-language risk indicator explanation for non-technical managers
- Recommended action

## Model Summary

| Model | Accuracy | Precision | Recall | F1 | AUC |
|---|---|---|---|---|---|
| **Random Forest** ✅ | 97.1% | 69.2% | 82.0% | 75.1% | 0.97 |
| Decision Tree | 91.4% | 35.1% | 77.3% | 48.3% | 0.85 |
| Logistic Regression | 85.6% | 23.2% | 71.3% | 34.8% | 0.86 |

> Metrics are for the **malicious class** on the held-out test set (20%).

**Random Forest was selected** for its highest recall (82%) on the minority malicious class,
highest AUC, and built-in feature importance for explainability.

## Dataset

- **Source:** Kaggle — `ahmeduzaki/insider-threat-dataset-for-corporate-environments`
- **Records:** 118,614 rows × 22 columns
- **Target:** `is_malicious` (0 = Normal, 1 = Malicious)
- **Class ratio:** 94.6% Normal / 5.4% Malicious
- **Imbalance handling:** SMOTE on training set only
